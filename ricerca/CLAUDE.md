# Area: ricerca

Qui finiscono le conclusioni delle ricerche. Un file per argomento: `ricerca/<argomento>.md` (kebab-case).

## Come si lavora

- La ricerca procede per più interazioni. Il file si scrive quando l'utente è arrivato alle sue conclusioni, o quando chiede di fissare il punto.
- Le conclusioni sono dell'utente: riportale fedelmente e segnala dove le fonti non le sostengono, senza riscriverle a modo tuo.
- Ogni affermazione importante ha una fonte con link. Preferisci fonti primarie (articoli, linee guida) alle divulgative.
- Se la ricerca vive in Notion, il file contiene il link alla pagina e un riassunto delle conclusioni. Con gli strumenti Notion puoi leggere la pagina per scriverlo.

## Modello

```markdown
# <Titolo>

**Domanda:** cosa volevamo capire.
**Stato:** in corso | conclusa
**Notion:** <link, se c'è>

## Conclusioni
I punti a cui si è arrivati, in ordine di importanza.

## Perché
Il ragionamento e i dati che sostengono le conclusioni.

## Fonti
- [Autore, titolo, anno](link): cosa dice, in una riga.

## Punti aperti
Quello che resta incerto o da approfondire.
```

Quando una ricerca è **conclusa** e l'utente vuole farne un video, si passa a `video/<stesso-nome>/`.
